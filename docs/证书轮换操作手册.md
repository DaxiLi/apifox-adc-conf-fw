# 证书轮换操作手册（SSL/TLS）

> 适用：本仓库（ADC + APISIX）管理的站点证书定期更换。
> 核心原则：**轮换时保持 `snis` 不变**——证书资源 ID = `sha1(snis)`（见
> [配置仓库结构设计.md](./配置仓库结构设计.md#51-ssl-证书放哪怎么换私钥放哪)），
> snis 不变 → 原地 update，不删旧建新、不中断 TLS。

---

## 1. 换之前：确认证书放哪

| 证书类型 | 文件 |
| ---- | ---- |
| 站点独有 | `configs/sites/<site-code>/ssl.yaml` |
| 通配证书 | `configs/global/ssls/wildcard.yaml` |
| 多站共用多 SAN | `configs/global/ssls/shared-<名称>.yaml` |
| 私钥方案（A 内联 / B `$env://` / C `$secret://`） | 见 [设计文档 5.1](./配置仓库结构设计.md#51-ssl-证书放哪怎么换私钥放哪) |

> 一张证书只在一个文件里定义一次；先确认目标文件里 `snis` 与你即将替换的一致。

---

## 2. 标准轮换流程（方案 A：内联 PEM）

```powershell
# ① 取新证书并本地检查（fullchain 服务器证书+中间链）
openssl x509 -in new-fullchain.pem -noout -subject -issuer -dates -fingerprint
openssl verify -CAfile <根CA或证书链> new-fullchain.pem        # 链完整性
# 私钥与证书是否匹配（两个 md5 应一致）
openssl x509 -noout -modulus -in new-fullchain.pem | openssl md5
openssl rsa -noout -modulus -in new-privkey.pem | openssl md5

# ② 替换 configs/sites/<site-code>/ssl.yaml 里的 certificate / key 内容
#    （snis、labels 等一律不动）

# ③ 校验 + 看差异：必须只出现 update/create，绝不能出现 delete
.\scripts\lint.ps1
.\scripts\diff.ps1

# ④ 确认后同步
.\scripts\sync.ps1

# ⑤ 验证线上证书已生效
openssl s_client -connect www.example.com:443 -servername www.example.com </dev/null 2>/dev/null |
  openssl x509 -noout -subject -dates -fingerprint
```

---

## 3. 方案 B / C：私钥不在仓库里时怎么换

| 方案 | 轮换动作 | 仓库要不要动 |
| ---- | ---- | ---- |
| B `$env://SSL_CERT` | 在**每台网关节点**更新环境变量/文件内容 → reload/重启 APISIX | 不用（YAML 不变） |
| C `$secret://vault/...` | 在 **Vault/AWS SM/GCP SM** 里更新 secret → 网关自动/触发重新拉取 | 不用（YAML 不变） |

> 注意（官方 secret.md 提示）：`$secret://` / `$env://` 引用会**跳过该字段的 schema 校验**；
> 若引用解析失败，字面引用串会被当值使用并写错误日志——换完务必按第 2 节第 ⑤ 步验证线上证书。

---

## 4. 到期提醒（定期更换的前提）

```powershell
openssl x509 -enddate -noout -in 现网证书.pem          # 查到期日
openssl s_client -connect 域名:443 -servername 域名 </dev/null 2>/dev/null |
  openssl x509 -noout -enddate                        # 查线上实际证书到期日
```

建议：到期前 1~2 周轮换；把各证书到期日登记到日历/监控（也可脚本定期 `adc dump` 后对 snis 逐个 `openssl` 检查）。

---

## 5. 回滚

- 方案 A：`git revert`（或手动改回上一版 PEM）→ `.\scripts\diff.ps1` 确认 → `.\scripts\sync.ps1`。
- 方案 B/C：在节点/Secret 管理器换回旧值即可。

---

## 6. 常见坑

| 坑 | 后果 | 避免 |
| ---- | ---- | ---- |
| 顺手改了 `snis` | 证书 ID 变 → **删旧建新**，短时中断 | 轮换时 snis 一个字符都别动 |
| 只放服务器证书、缺中间链 | 客户端链校验失败 | 用 fullchain（服务器证书 + 中间链拼接） |
| 私钥与证书不匹配 | 握手失败 | 换前用第 2 节 ① 的 md5 比对 |
| 内联 PEM 缺 `-----BEGIN/END-----` 行 | schema 校验失败 / 网关报错 | 保持完整格式（certificate ≥128、key ≥32 字符） |
| 忘记在多节点同步 `$env://` | 部分节点旧证书 | 方案 B 轮换后逐个节点验证 |
